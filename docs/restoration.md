## Интерфейс и демоданные

Сохранены исходные страницы главной, «О нас», тарифов, входа, портфеля,
профиля, торговли, новостей и 404, стили SCSS, animate.css, бегущие отзывы
react-ticker, логотипы, иллюстрации и меню. «Бизнесу» и «Обучение» остались
ссылками на исходную страницу 404 (в оригинале не реализованы). Пароль/регистрация удалены,
на экране входа — готовый демопользователь; прямой вход в кабинет доступен сразу.
Устранён исходный вызов незаполненного callback меню, мешавший переходам.

Демопользователь — **Алексей Демо**, `demo@example.com`, без пароля.
Начальный свободный баланс — **10 000$**, позиции:

Активы — 3 040$, весь счёт — 13 040$. Каталог из восьми инструментов:
AAPL, MSFT, AMD, GOOGL, TSLA, AMZN, NVDA, SPY. Цены и валютные курсы условные,
фиксированные, **не текущие и не исторические биржевые котировки**.
Комиссия покупки и продажи — 0,04% с округлением до цента.
Исправлены исходные 4% при покупке и удаление всей позиции при частичной продаже.

Покупка, продажа, пополнение и списание требуют одного подтверждения.
Заявка получает устойчивый ID; повторное выполнение того же ID не меняет счёт.
Расчёты — целые центы. Данные сохраняются одним JSON после полной проверки.
Сбой записи не выдаётся за выполненную операцию. Web Locks сериализуют
одновременные записи разных вкладок; storage events обновляют интерфейс.
Вкладки одного browser profile используют общий счёт, разные профили/контексты
полностью независимы. Сброс очищает операции и возвращает профиль/портфель.
Сервер не получает и не хранит эти данные. Хранилище: `honest-broker.demo.v1`.

Локальные учебные новости вымышлены, датированы 15–18.03.2022 и подписаны
«Учебная редакция». Все ресурсы локальные: Montserrat с OFL, аватар и условная
карта офиса. Оригинальные внешние ссылки на контакты открываются только по клику.
Firebase, Tradernet, Marketaux, cookie-пароли и API credentials удалены из
приложения и зависимостей. CSP запрещает сетевые соединения приложения
(`connect-src 'none'`); скрипты, шрифты и изображения — с того же origin, внешние iframe запрещены.

## Разработка и проверка

В этом checkout команды npm/node/Docker направлены на big-one.
Перед запуском проверить `command -v node npm docker`, синхронизацию Mutagen.

```sh
npm ci --no-audit --no-fund
npm test
npm run lint
PARCEL_WORKERS=2 NODE_OPTIONS=--max-old-space-size=1536 npm run build
npm start -- --host 127.0.0.1
npm run test:browser -- http://127.0.0.1:1234 /tmp/honest-broker-qa
```

Browser tests требуют Playwright Chromium (`npx playwright install chromium`
на big-one, если browser cache отсутствует). Локальные localhost-проверки
и production HTTPS дают secure context для Web Locks и crypto.randomUUID.
Старый браузер без этих возможностей получает явную ошибку сохранения.
Размер демобаланса ограничен 100 000 000$, количества — 1 000 000 шт.

## Production и восстановление

Единственный сервис `honest-broker/web`, контейнер `honest-broker`.
Маршрут Caddy: `broker.ilyamedve.dev`, сеть `caddy_net`, upstream 8080.
Портов на хосте, серверной БД, volumes, credentials, фоновых jobs нет.
Nginx работает от непривилегированного пользователя, rootfs read-only,
64 MiB RAM, 0,5 CPU, 64 PID, tmpfs 16 MiB. Healthcheck `/healthz` проверяет
HTTP nginx; бизнес-сценарии подтверждаются отдельно браузером.
Логи ограничены 3 × 5 MiB, access log приложения отключён.

```sh
docker compose build --build-arg SOURCE_REVISION="$(git rev-parse HEAD)" web
docker compose up -d --no-deps --no-build --pull never --wait --wait-timeout 90 web
```

Compose зарегистрирован в server/scripts/bootstrap/production-stacks.yml;
recovery.yml содержит явную статическую схему восстановления.
Исходники и lockfile плюс зафиксированные base-image digests позволяют пересборку.
Готовый образ, release manifest, source bundle и исходная ревизия сохраняются
на big-one отдельно от рабочего дерева; точные пути/хеши — в release-report.md.

Для чистого восстановления: вернуть checkout/source bundle, создать caddy_net
и Caddy обычным bootstrap, загрузить сохранённый образ (`docker load -i ...`)
или пересобрать его, затем запустить только этот Compose stack. Не выполнять
общий `up` по автоматически найденным файлам.

Отдельный app backup на DE **не требуется**: невоспроизводимого серверного
состояния нет. Данные localStorage намеренно не включены в DE snapshot.
Текущая активная схема server — ежедневная проверенная DE-копия; пауза
Яндекс.Диска сохраняется. Новых секретов/ключей и Restic repositories нет.
Ручное обновление общей recovery-заметки выполняет владелец через свой клиент;
подготовка encrypted export не подтверждает загрузку в Bitwarden.

## Откат

Это первая публикация на ранее свободном домене: прежнего образа брокера нет.
Для снятия демо с публикации остановить **только** `web` этого стека:

```sh
docker compose stop web
```

Caddy автоматически уберёт upstream после события Docker, соседей не
перезапускать и не перезагружать базовый Caddyfile. Для возврата выпуска
загрузить сохранённый образ, сверить image ID и запустить приведённую команду.
Перед следующими выпусками помечать текущий image immutable rollback tag,
сохранять Compose manifest и проверять тот же браузерный набор.
